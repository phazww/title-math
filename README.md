# Title Math

What every driver needs in the 2026 F1 championship: the points gap, who is still alive, when the title can be decided, and a race-by-race scenario builder with shareable links.

Live: https://phazww.github.io/title-math/

Update `data.js` after every race: points, wins, and remove the finished race from `RACES`.

Unofficial fan project. Not affiliated with Formula 1, the FIA or any team.
